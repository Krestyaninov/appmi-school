# 🎓 AppMi School — Интерактивный тренажёр и база знаний по роботам-пылесосам

Интерактивный веб-тренажёр и структурированная база знаний по роботам-пылесосам (**Dreame**, **Roborock**, **Dyson**) для менеджеров и процессора распознавания товаров v6 сети [AppMiStore.ru](https://appmistore.ru/).

🔗 **URL тренажёра:** [https://krestyaninov.github.io/appmi-school/](https://krestyaninov.github.io/appmi-school/)

---

## 🎯 Цели проекта

1. **База знаний для процессора распознавания товаров v6**  
   Формализованные правила сегментации, суффиксы, расшифровка артикулов/партномеров и соответствие маркетинговых названий аппаратным кодам (CE/EU/AE/RU) для точного парсинга и сопоставления предложений от поставщиков.

2. **Обучающий тренажёр для менеджеров по продажам**  
   Интерактивное пособие, позволяющее сотрудникам быстро изучить иерархию линеек, позиционирование моделей, различия модификаций (Pro, Ultra, Master, Plus, MaxV), ориентироваться в ценах каталога и безошибочно подбирать устройства под задачи клиентов.

---

## 🚀 Режимы работы

- **📖 Справочник (Reference):**
  - **🏷️ Линейки** — сегментация, позиционирование, ценовые диапазоны, ключевые модели (Dreame: D/L/X/Aqua/F; Roborock: Saros/S/Qrevo/Q/E/V; Dyson: 360 Eye/Heurist/Vis Nav).
  - **📊 Иерархия** — визуальная шкала цен от бюджетных к флагманам с цветовой индикацией позиций нашего магазина.
  - **🔤 Имя модели (Decoder)** — интерактивный разбор формулы названия робота по клику на каждую часть.
  - **🔢 Партномер** — расшифровка кодов моделей (RLL..., RLX..., EWFD..., RB03...) и станций, чек-лист для сверки поставок.
  - **📌 Суффиксы** — полный справочник значений (Pro, Ultra, Master, Slim, Track, CE, Curv, Edge, SpiraFlow).
  - **📋 Таблица** — каталог моделей с фильтрацией по линейкам, ценами, наличием и флагом наличия в AppMiStore.
  - **⚠️ Ловушки** — типовые ошибки менеджеров и поставщиков (путаница L50 Ultra CE и L50 Ultra, теги «NEW», док-станции vs пылесосы).
  - **⚖️ Dyson vs флагманы** — детальная матрица сравнения подхода Dyson (камера + гусеницы + мощность без влажной уборки) с китайскими флагманами (станции полного цикла).

- **⚡ Практика (Practice):**
  - Тренировочные вопросы с фильтрацией по темам (Линейки, Суффиксы, Партномера, Каталог, Ловушки).
  - Моментальная обратная связь с разбором правильного ответа и подсказками для консультаций.

- **🏆 Экзамен (Exam):**
  - 20 вопросов по бренду в условиях ограничения времени (15 минут).
  - Навигационная сетка вопросов, возможность пропуска и возврата.
  - Итоговый процент правильных ответов, порог сдачи 70%, подробный отчёт с разбором ошибок.

## 🛠️ Локальный запуск

Проект полностью статичный (Vanilla JS + HTML5 + CSS3) и не требует сборщиков или сервера node.js.

Запустить локальный веб-сервер в директории проекта:
```bash
python3 -m http.server 8080
```
Затем открыть в браузере: `http://localhost:8080`

## ➕ Как добавить новые вопросы или модели

- **Добавить модель в каталог:** откройте соответствующий файл в папке `data/` (`dreame.js`, `roborock.js` или `dyson.js`) и добавьте объект в массив `catalog`:
```javascript
{
  id: "l60-pro-ultra-white",
  name: "L60 Pro Ultra",
  series: "L",
  suffixes: ["Pro", "Ultra"],
  region: "CE",
  color: "White",
  price: 83500,
  inStock: true,
  inOurCatalog: true,
  isNew: true,
  partnum: "RLL63SE",
  features: ["Автосбор пыли", "Мойка горячей водой", "Выдвижная ножка"],
  positioning: "Топ линейки L, предфлагман"
}
```

- **Добавить вопрос в квиз/экзамен:** добавьте объект в массив `quiz`:
```javascript
{
  id: "dr-q21",
  topic: "suffixes",
  difficulty: "medium",
  prompt: "Что означает суффикс Master в линейке Dreame?",
  options: [
    "Версия с увеличенной емкостью пылесборника",
    "Ультракомпактная заниженная станция под встраивание в мебель (подключение к водопроводу)",
    "Версия только для коммерческих помещений",
    "Комплектация с расширенным набором моющих средств"
  ],
  answer: 1,
  explain: "Master у Dreame обозначает ультракомпактную базу со скрытым монтажом и прямым подключением к водопроводу и канализации."
}
```
